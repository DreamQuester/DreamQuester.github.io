# 조건문

## 조건문이란?
조건문은 특정 조건에 따라 프로그램의 흐름을 제어하는 구조입니다. 

- **if**: 조건이 참이면 if문 안의 로직을 실행합니다.
- **elif**: if 조건이 틀리고 현재 조건이 맞을 때 실행됩니다.
- **else**: if/elif 조건이 다 틀렸을 때 실행됩니다.

조건문 안에 수행할 내용은 들여쓰기하여 작성합니다.

```python
# 사용자로부터 점수 입력 받기
score = int(input("점수를 입력하세요: "))

# 조건문을 사용한 점수 평가
if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
elif score >= 70:
    print("C학점")
elif score >= 60:
    print("D학점")
else:
    print("F학점")
```

# 반복문

## For 문
### For 문이란?
`for` 문은 반복 가능한 객체(리스트, 튜플, 문자열 등)의 요소를 하나씩 꺼내어 처리하는 구조입니다. 형태는 아래와 같다.

```python
for 변수 in 리스트, 튜플, 문자열 (반복 가능한 객체):
    처리할 구문
```

```python
# 리스트 요소 출력
fruits = ['사과', '바나나', '오렌지']

for fruit in fruits:
    print("과일:", fruit)
```
```markdown
과일: 사과
과일: 바나나
과일: 오렌지
```

## While 문
### While 문이란?
조건문이 True 인 동안 while 문 안의 문장이 반복해서 실행된다. 특정 상황에서 반복을 중지하기 while 문 안에서 조건을 제어한다. 형태는 아래와 같다.

```python
while 조건문:
 처리
```

```python
# 1부터 5까지의 합을 구하는 예시
total = 0
count = 1

while count <= 5:
    total += count
    count += 1  # count를 1씩 증가시킴

print("1부터 5까지의 합:", total)
```
```markdown
1부터 5까지의 합: 15
```

### 제어문
- **`break`**: 반복문 안에서 특정 조건이 되어 반복문을 빠져 나올 때 사용한다. `for` 문과 `while` 문 모두에 적용할 수 있다.
- **`continue`**: 반복문을 중단시키지 않고 다음 반복으로 넘어갈 때 사용한다.

```python
# 1부터 10까지의 숫자 중 5를 만나면 반복 종료하고 홀수는 건너뛰기
for i in range(1, 11):
    if i == 5:
        print("5를 만나서 반복을 종료합니다.")
        break
    if i % 2 != 0:  # 홀수일 경우
        continue
    print(i)
```
```markdown
2
4
5를 만나서 반복을 종료합니다.
```

## 리스트/ 튜플로 반복
반복할 범위를 리스트/튜플로 정하여 반복할 수 있다.

```python
# 과일 리스트
fruits = ['사과', '바나나', '오렌지']

# 리스트의 각 요소를 반복
for fruit in fruits:
    print("과일:", fruit)
```
```markdown
과일: 사과
과일: 바나나
과일: 오렌지
```

## enumerate()
`enumerate()` 함수는 반복할 때 인덱스와 함께 값을 반환한다. 몇 번째 반복인지 알 수 있어 유용하다.

```python
# 과일 리스트
fruits = ['사과', '바나나', '오렌지']

# enumerate를 사용하여 인덱스와 함께 반복
for index, fruit in enumerate(fruits):
    print(f"{index + 1}번째 과일: {fruit}")
```
```markdown
1번째 과일: 사과
2번째 과일: 바나나
3번째 과일: 오렌지
```

## 리스트 컴프리헨션(List Comprehension)
리스트 컴프리헨션을 사용하여 복잡한 반복문을 작성하지 않고 조건에 맞는 데이터만 가져올 수 있다.

```python
# 0부터 8까지의 숫자를 포함하는 리스트 생성
lst = list(range(9))

# 홀수 리스트 생성
lst_odd = [x for x in lst if x % 2 == 1]

# 짝수 리스트 생성
lst_even = [x for x in lst if x % 2 == 0]

# 제곱값 리스트
squared_numbers = [x**2 for x in range(10)]

# 결과 출력
print(lst_odd)   # 홀수 리스트 출력
print(lst_even)  # 짝수 리스트 출력
print(squared_numbers)  # 제곱값 리스트 출력
```
```markdown
[1, 3, 5, 7]
[0, 2, 4, 6, 8]
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```
