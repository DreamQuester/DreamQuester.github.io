# Python 개념 정리
* 주석 (comment): “#” 버튼 이후는 코드가 아닌 주석으로 처리되어 실행되지 않는다.
이때 코드와 같은 줄이어도 상관 없다.

```python
# 이 코드는 주석입니다. 실행되지 않습니다.
print("안녕하세요!")  # 이 부분도 주석입니다.
```
```markdown
안녕하세요!
```

* 변수 (variable): 변수는 데이터를 저장하는 이름이다. 변수는 특정 데이터를 담고 있으며, 
이 데이터는 숫자, 문자열, 리스트 등 다양한 형태일 수 있다. 알파벳, 숫자, 언더바(_) 를 조합하여 사용한다.
숫자와 특수기호로 시작할 수 없다.

```python
나이 = 25
이름 = "홍길동"
print("이름:", 이름, "나이:", 나이)
```
```markdown
이름: 홍길동 나이: 25
```

* 함수 (function): 함수란 어떠한 로직 처리를 위해 미리 작성되어 모듈화 된 코드이다. 
  예를 들어, 파이썬에서의 `print()` 함수는 미리 구현되어 있는 내장함수로 변수의 값, 연산 결과 등을 확인한다.

```python
def 인사(이름):
    print("안녕하세요,", 이름)

인사("홍길동")
```  
```markdown
안녕하세요, 홍길동
```

# Python의 데이터 타입
## Number(숫자형)
### 숫자형의 종류
• int(): 정수  
• float(): 실수  
• complex(): 복소수  
• 2진수, 8진수, 16진수  
`type()` 함수로 변수의 자료형을 파악할 수 있다.
```python
# 정수 (int)
정수 = 10
print("정수:", 정수, "형:", type(정수))

# 실수 (float)
실수 = 3.14
print("실수:", 실수, "형:", type(실수))

# 복소수 (complex)
복소수 = 2 + 3j
print("복소수:", 복소수, "형:", type(복소수))

# 2진수, 8진수, 16진수
이진수 = 0b1010  # 2진수
팔진수 = 0o12    # 8진수
십육진수 = 0xA   # 16진수

print("2진수:", 이진수, "형:", type(이진수))
print("8진수:", 팔진수, "형:", type(팔진수))
print("16진수:", 십육진수, "형:", type(십육진수))
```
```markdown
정수: 10 형: <class 'int'>
실수: 3.14 형: <class 'float'>
복소수: (2+3j) 형: <class 'complex'>
2진수: 10 형: <class 'int'>
8진수: 10 형: <class 'int'>
16진수: 10 형: <class 'int'>
```

### 비교 연산자
비교 연산자는 값의 크기를 비교할 때, 값이 같은지 다른지 확인할 때때 사용하는 연산자이다.
결과값으로 **True** 또는 **False** 를 반환한다.

| 연산자 | 의미                     |
|--------|--------------------------|
| `a > b` | a가 b보다 크다          |
| `a < b` | a가 b보다 작다          |
| `a >= b` | a가 b보다 크거나 같다   |
| `a <= b` | a가 b보다 작거나 같다   |
| `a != b` | a와 b는 다르다         |
| `a == b` | a와 b는 같다           |


### 산술 연산자
산술 연산자는 값을 더하거나 빼는 등의 처리를 하는 연산자이다.

| 연산자 | 의미                     |
|--------|--------------------------|
| `a + b` | a 더하기 b              |
| `a - b` | a 빼기 b                |
| `a * b` | a 곱하기 b              |
| `a / b` | a 나누기 b              |
| `a // b` | a를 b로 나눈 몫       |
| `a % b` | a를 b로 나눈 나머지     |
| `a ** b` | a의 b제곱             |


### 복합 대입 연산자
복합 대입연산자는 연산과 변수에 값 대입을 동시에 수행하는 연산자로, 
구문이 더 짧아 가독성이 좋아진다.  

| 연산자  | 의미                     |
|---------|--------------------------|
| `a += b` | a = a + b               |
| `a -= b` | a = a - b               |
| `a *= b` | a = a * b               |
| `a /= b` | a = a / b               |
| `a //= b` | a = a // b             |
| `a %= b` | a = a % b               |
| `a **= b` | a = a ** b             |


## String(문자열)
### String이란?
문자열은 문자와 단어로 이루어진 데이터로, 큰 따옴표 (“ ”) 나 작은 따옴표 (‘ ’) 로 생성한다.
파이썬은 문자연에 대한 다양한 메소드를 지원한다.
문자열끼리 더하기는 문자열을 결합하고, 문자열에 숫자를 곱하면 지정한 숫자만큼 문자열이 반복한다.
```python
# 문자열 생성
string1 = "안녕하세요"
string2 = '파이썬'

# 문자열 결합
combined_string = string1 + " " + string2
print("결합된 문자열:", combined_string)

# 문자열 반복
repeated_string = string1 * 3
print("반복된 문자열:", repeated_string)
```
```markdown
결합된 문자열: 안녕하세요 파이썬
반복된 문자열: 안녕하세요안녕하세요안녕하세요
```
<br>

print() 함수로 문자열을 표현할 때에는 `"문자열".format()` 의 형태를 사용한다.
문자열 안에 나타내고 싶은 변수의 위치에 대괄호 {} 를 삽입하여 변수 표현이 가능하다.
format() 안에는 나타내고 싶은 순서대로 변수가 위치해야 한다.
```python
# 변수 정의
name = "홍길동"
age = 25
job = "개발자"

# format() 메소드를 사용한 문자열 표현
output_string = "이름: {}, 나이: {}, 직업: {}".format(name, age, job)
print(output_string)

# f-string을 사용한 방법 (파이썬 3.6 이상)
output_string_f = f"이름: {name}, 나이: {age}, 직업: {job}"
print(output_string_f)
```
```markdown
이름: 홍길동, 나이: 25, 직업: 개발자
이름: 홍길동, 나이: 25, 직업: 개발자
```
<br>

### 문자열 관련 주요 메소드
메소드란 변수 뒤에 `.method()` 형태로 사용하는 함수이다. 파이썬에서는 다양한 메소드를 지원하고 있다.  
* `split(x)`: 입력으로 들어간 x 문자를 구분자로 하여 문자열을 분리하여 리스트로 반환, 구분자를 지정하지 않으면 공백이 구분자가 된다.

```python
# 문자열 생성
string = "Python은 재미있고, 강력한 프로그래밍 언어입니다."

# 기본 구분자 (공백)로 분리
word_list = string.split()
print("기본 구분자로 분리된 리스트:", word_list)

# 특정 구분자 (쉼표)로 분리
string2 = "사과,바나나,딸기"
fruit_list = string2.split(",")
print("쉼표로 분리된 리스트:", fruit_list)
```
```markdown
기본 구분자로 분리된 리스트: ['Python은', '재미있고,', '강력한', '프로그래밍', '언어입니다.']
쉼표로 분리된 리스트: ['사과', '바나나', '딸기']
```
<br>

* `"x".join(y)`: y의 모든 요소를 x를 구분자로 하여 연결한 문자열을 반환한다다. y에는 리스트나 튜플과 같은 데이터 컨테이너가 들어가야 한다.

```python
# 리스트 생성
fruits = ["사과", "바나나", "딸기"]

# 구분자로 쉼표와 공백을 사용하여 연결
joined_string = ", ".join(fruits)
print("구분자로 연결된 문자열:", joined_string)

# 튜플 생성
vegetables = ("감자", "당근", "양파")

# 구분자로 하이픈을 사용하여 연결
joined_string_tuple = " - ".join(vegetables)
print("튜플로 연결된 문자열:", joined_string_tuple)
```
```markdown
구분자로 연결된 문자열: 사과, 바나나, 딸기
튜플로 연결된 문자열: 감자 - 당근 - 양파
```
<br>

* `upper()`: 모든 문자를 대문자로 바꾼 문자열을 반환한다.
* `lower()`: 모든 문자를 소문자로 바꾼 문자열을 반환한다.
* `capitalize()`: 문자열 첫 글자는 대문자, 나머지는 모두 소문자로 바꾼 문자열을 반환한다.

```python
# 문자열 생성
text = "hello, world!"

# 모든 문자를 대문자로 변환
upper_text = text.upper()
print("대문자로 변환:", upper_text)

# 모든 문자를 소문자로 변환
lower_text = text.lower()
print("소문자로 변환:", lower_text)

# 첫 글자는 대문자, 나머지는 소문자로 변환
capitalize_text = text.capitalize()
print("첫 글자 대문자 변환:", capitalize_text)
```
```markdown
대문자로 변환: HELLO, WORLD!
소문자로 변환: hello, world!
첫 글자 대문자 변환: Hello, world!
```

## Boolean(불리안, 참/거짓)
참과 거짓을 표현하는 데이터이다. 로직이 동작하게 하는 기본 요소로 논리 연산자를 이용하여 연산한다.

* **A and B**: A와 B가 모두 True이면 True
* **A or B**: A와 B 둘 중 하나라도 True이면 True
* **not A**: A의 논리 반대

```python
# 변수 정의
A = True
B = False

# 논리 연산
and_result = A and B  # A와 B가 모두 True이면 True
or_result = A or B    # A와 B 둘 중 하나라도 True이면 True
not_result = not A     # A의 논리 반대

# 결과 출력
print("A and B:", and_result)  # False
print("A or B:", or_result)    # True
print("not A:", not_result)     # False
```
```markdown
A and B: False
A or B: True
not A: False
```
