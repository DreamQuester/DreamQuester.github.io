# 함수
## 함수란?
함수란 입력을 받아 무엇인가를 처리한 후 그 결과를 반환하는 것이다. 프로그래밍에서 함수란 반복해 사용할 코드를 미리 정의해두고 필요할 때 사용하는 모듈로, 같은
로직을 반복해서 코딩할 필요가 없어진다.

```python
def add(a, b):
    return a + b

# 함수 호출
result = add(3, 5)
print("3과 5의 합:", result)
```
```markdown
3과 5의 합: 8
```

## 함수의 입력과 출력

대부분의 함수는 매개변수를 입력 받아 처리한 후 결과값을 반환한다. 하지만 입력 매개변수가 없거나 반환되는 값이 없을 수 있다.

```python
# 매개변수를 받아서 결과를 반환하는 함수
def multiply(a, b):
    return a * b

# 매개변수가 없는 함수
def greet():
    return "안녕하세요!"

# 반환값이 없는 함수
def print_message(message):
    print("메시지:", message)

# 함수 호출
result = multiply(4, 5)
greeting = greet()
print_message("함수가 호출되었습니다.")

# 결과 출력
print("4와 5의 곱:", result)
print(greeting)
```
```markdown
메시지: 함수가 호출되었습니다.
4와 5의 곱: 20
안녕하세요!
```

## 함수와 변수
기본적으로 함수는 함수 밖의 변수를 변경할 수 없다. 함수는 def 구문 안에 있는 변수에만 권한이 있다. 변수를 변경하려면 반환된 값을 받거나 global 키워드를 사용해야 한다.

### 함수와 변수의 범위
```python
# 전역 변수
count = 10

def increment():
    global count  # 전역 변수 사용 선언
    count += 1

# 반환값을 사용하여 변수 변경하기
def increment_with_return(count):
    return count + 1

# 함수 호출
increment()  # count는 이제 11이 됩니다.
count_returned = increment_with_return(count)  # count는 11이므로 12로 반환됩니다.

# 결과 출력
print("변경된 count (global 사용):", count)
print("변경된 count (return 사용):", count_returned)
```
```markdown
변경된 count (global 사용): 11
변경된 count (return 사용): 12
```

### 함수의 다중 반환값
여러 개의 값을 한 번에 받을 때, 함수가 반환하는 값이 여러 값일 경우 개수에 맞춰 변수를 할당해주어야 한다. 이때 원하지 않는 값일 경우 ‘_’ 표시로 반환을 생략할 수 있다. 하나의 변수로 여러 값을 받을 때는 하나의 변수가 여러 값을 지닌 튜플이 된다.

```python
# 두 값을 반환하는 함수
def calculate(a, b):
    sum_value = a + b
    diff_value = a - b
    return sum_value, diff_value

# 두 개의 변수로 반환값 받기
result_sum, result_diff = calculate(10, 5)

# 원하지 않는 값을 생략할 때
_, result_diff_skip = calculate(20, 8)

# 하나의 변수로 여러 값을 받을 때
result_tuple = calculate(30, 15)

# 결과 출력
print("합:", result_sum)
print("차:", result_diff)
print("생략 후 차:", result_diff_skip)
print("튜플로 받은 결과:", result_tuple)
```
```markdown
합: 15
차: 5
생략 후 차: 12
튜플로 받은 결과: (45, 15)
```

### 가변 인자와 딕셔너리 인자
입력하는 변수가 큰 수인 n일 때 n개를 전부 함수 input으로 적어주는 것이 아닌 *를 사용한다. 그리고 함수의 input으로 딕셔너리를 사용하는 경우 *를 두 개 사용하여 받는다.

```python
# 가변 인자를 받는 함수
def sum_all(*args):
    return sum(args)

# 딕셔너리 인자를 받는 함수
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

# 가변 인자 사용
result = sum_all(1, 2, 3, 4, 5)

# 딕셔너리 인자 사용
print_info(name="홍길동", age=30, city="서울")

# 결과 출력
print("합계:", result)
```
```markdown
name: 홍길동
age: 30
city: 서울
합계: 15
```

# 클래스
## 클래스란?
클래스는 객체 지향 프로그래밍에서 객체를 생성하기 위한 청사진(설계도)이다. 클래스는 속성과 메서드를 정의하여 관련된 데이터를 구성하고, 이 데이터를 처리하는 방법을 제공한다.

## 클래스의 필요성
1. **코드의 재사용성**: 클래스는 객체를 여러 번 생성할 수 있게 해 주므로, 동일한 코드를 반복해서 작성할 필요가 없다.
2. **유지보수 용이성**: 클래스 내의 메서드와 속성을 수정하면, 해당 클래스를 사용하는 모든 객체에 영향을 미치므로 코드 유지보수가 쉬워진다.
3. **추상화**: 복잡한 시스템을 단순화하여, 사용자에게 필요한 기능만을 제공할 수 있게 한다.
4. **상속**: 기존 클래스를 기반으로 새로운 클래스를 만들 수 있어 코드의 확장성과 재사용성을 높인다.

```python
class Dog:
    def __init__(self, name, age):
        self.name = name  # 속성: 이름
        self.age = age    # 속성: 나이

    def bark(self):  # 메서드: 짖기
        return f"{self.name}가 멍멍 짖습니다!"

    def get_info(self):  # 메서드: 정보 출력
        return f"이름: {self.name}, 나이: {self.age}살"

# 클래스 인스턴스 생성
my_dog = Dog("코코", 3)
your_dog = Dog("보리", 2)

# 메서드 호출
bark_sound1 = my_dog.bark()
dog_info1 = my_dog.get_info()
bark_sound2 = your_dog.bark()
dog_info2 = your_dog.get_info()

# 결과 출력
print(bark_sound1, bark_sound2)
print(dog_info1, dog_info2)
```
```markdown
코코가 멍멍 짖습니다! 보리가 멍멍 짖습니다!
이름: 코코, 나이: 3살 이름: 보리, 나이: 2살
```

## 간단한 클래스의 예시 코드
`def__init__(self, ...)`: 클래스를 통해 객체를 생성할 때부터 변수 선언이 가능하다.  
`def method(param1, ...)`: 클래스 내의 함수는 메소드라 부른다.

LibraryMember 클래스의 목적은 도서관 회원을 관리하기 위함이다. 이 클래스는 다음과 같은 기능을 제공한다.
1. 초기화: 회원의 이름과 대출한 책의 수를 초기화한다.  
`__init__(self, name)`: 이름을 매개변수로 받아서 초기화한다.  
2. 책 대출: 회원이 책을 대출할 때 호출되는 메서드이다.  
`borrow(self, books)`: 대출한 책의 수를 증가시키고, 대출 완료 메시지를 출력한다.  
3. 책 반납: 회원이 책을 반납할 때 호출되는 메서드이다.  
`return_books(self, books)`: 반납할 책의 수를 확인하고, 가능할 경우 대출한 책의 수를 감소시킨다.
4. 대출 현황 확인: 현재 대출 중인 책의 수를 확인하는 메서드이다.
`balance(self)`: 대출 중인 책의 수를 출력한다.

```python
# 클래스 정의
class LibraryMember:
    def __init__(self, name):
        self.name = name  # 회원의 이름
        self.borrowed_books = 0  # 대출한 책의 수

    def borrow(self, books):
        self.borrowed_books += books
        print(f"{self.name}님이 {books}권의 책을 대출했습니다.")

    def return_books(self, books):
        if books > self.borrowed_books:
            print("반납할 수 있는 책 수가 부족합니다.")
        else:
            self.borrowed_books -= books
            print(f"{self.name}님이 {books}권의 책을 반납했습니다.")

    def balance(self):
        print(f"{self.name}님은 현재 {self.borrowed_books}권의 책을 대출 중입니다.")

# 클래스 인스턴스 생성
member = LibraryMember("김철수")

# 책 대출
member.borrow(3)  # 김철수가 3권의 책을 대출
member.balance()   # 현재 대출 중인 책 수 확인

# 책 반납
member.return_books(1)  # 김철수가 1권의 책을 반납
member.balance()         # 현재 대출 중인 책 수 확인

# 부족한 반납 시도
member.return_books(5)  # 반납할 수 있는 책 수 부족
```
```markdown
김철수님이 3권의 책을 대출했습니다.
김철수님은 현재 3권의 책을 대출 중입니다.
김철수님이 1권의 책을 반납했습니다.
김철수님은 현재 2권의 책을 대출 중입니다.
반납할 수 있는 책 수가 부족합니다.
```

## 클래스의 상속
상속은 보통 기존 클래스를 변경하지 않고 기능을 추가하거나 기존 기능을 변경할 때 사용한다. 기존 클래스가 라이브러리 형태로 제공되거나 수정이 허용되지 않는 상황이라면 상속을 해야한다.  
아래의 PremiumMember 클래스는 LibraryMember 클래스를 상속받아, 프리미엄 도서관 회원의 연회비와 최대 대출 가능 책 수를 관리하며, 추가 대출 혜택을 제공한다. 이 클래스는 대출 시 최대 대출 수를 확인하는 기능도 포함되어 있다.

```python
# 프리미엄 도서관 회원 클래스 (상속)
class PremiumMember(LibraryMember):
    def __init__(self, name, annual_fee, max_borrow_limit):
        super().__init__(name)  # 부모 클래스 초기화
        self.annual_fee = annual_fee  # 연회비
        self.max_borrow_limit = max_borrow_limit  # 최대 대출 가능 책 수

    def borrow(self, books):
        if self.borrowed_books + books > self.max_borrow_limit:
            print(f"{self.name}님은 최대 대출 수를 초과할 수 없습니다. 최대 대출 가능 책 수: {self.max_borrow_limit}권")
        else:
            super().borrow(books)  # 부모 클래스의 borrow 메서드 호출
            print(f"{self.name}님은 프리미엄 회원으로서 추가 혜택을 받습니다.")

    def special_borrow(self, books):
        self.borrowed_books += books
        print(f"{self.name}님이 특별 대출로 {books}권의 책을 추가로 대출했습니다.")

    def info(self):
        print(f"{self.name}님은 연회비가 {self.annual_fee}원이며, 최대 대출 가능 책 수는 {self.max_borrow_limit}권입니다.")

# 클래스 인스턴스 생성
premium_member = PremiumMember("이영희", 30000, 10)

# 프리미엄 도서관 회원 정보 확인
premium_member.info()

# 프리미엄 도서관 회원 대출
premium_member.borrow(3)
premium_member.balance()

# 프리미엄 회원의 특별 대출
premium_member.special_borrow(2)
premium_member.balance()

# 최대 대출 수 초과 시도
premium_member.borrow(8)  # 10권을 초과하려는 시도
```
```markdown
이영희님은 연회비가 30000원이며, 최대 대출 가능 책 수는 10권입니다.
이영희님이 3권의 책을 대출했습니다.
이영희님은 프리미엄 회원으로서 추가 혜택을 받습니다.
이영희님은 현재 3권의 책을 대출 중입니다.
이영희님이 특별 대출로 2권의 책을 추가로 대출했습니다.
이영희님은 현재 5권의 책을 대출 중입니다.
이영희님은 최대 대출 수를 초과할 수 없습니다. 최대 대출 가능 책 수: 10권
```
