# 예외 처리
## 파이썬에서 발생하는 주요 에러

| 에러명                  | 간단한 설명                                                |
|----------------------|---------------------------------------------------------|
| **ValueError**        | 부적절한 값을 가진 인자를 받았을 때 발생                  |
| **IndexError**        | 리스트의 인덱스 범위를 벗어났을 때 발생                   |
| **SyntaxError**       | 파이썬 문법 오류가 발생했을 때 발생                        |
| **NameError**         | 정의되지 않은 변수를 참조하려 할 때 발생                   |
| **ZeroDivisionError**  | 0으로 나누려 할 때 발생                                    |
| **FileNotFoundError**  | 요청한 파일이 존재하지 않을 때 발생                        |
| **TypeError**         | 데이터 타입이 맞지 않을 때 발생                             |
| **AttributeError**    | 객체에 존재하지 않는 속성이나 메서드를 호출할 때 발생        |
| **KeyError**          | 딕셔너리에 존재하지 않는 키를 참조하려 할 때 발생           |
| **OverFlowError**     | 연산 결과가 데이터를 표현할 수 있는 범위를 초과할 때 발생  |

## 예외 처리란?
파이썬은 try, except 를 사용해서 예외적으로 오류를 처리할 수 있게 한다. try, except에서 except에 특정 오류만 처리할 수 있다.  
```python
try:
    # 무엇인가를 하고
except [발생 오류[as 오류 메시지 변수]]: 
    # try블록에서 오류가 발생하면 여기서 처리한다.
    # 오류가 발생하지 않으면 except블록이 수행되지 않는다.
```

## 예시 코드
```python
try:
    # 위험할 수 있는 코드
    result = 10 / 0  # ZeroDivisionError 발생
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
```
```markdown
0으로 나눌 수 없습니다.
```

## pass
**pass**는 다음 코드를 실행시킨다. try 구문에서 없는 txt 파일을 읽는 과정에서 에러가 발생하지만, except 구문에서 pass로 인해 프로그램이 멈추지 않고 진행된다.  
아래는 pass를 사용하여 예외 처리를 수행하는 예시 코드이다. 이 코드는 존재하지 않는 텍스트 파일을 읽으려 할 때 발생하는 FileNotFoundError를 처리한다. pass를 사용하면 에러가 발생해도 프로그램이 중단되지 않고 계속 진행된다.
```python
def read_file(file_name):
    try:
        # 파일을 읽기 모드로 열기
        with open(file_name, 'r') as file:
            content = file.read()
            print(content)
    except FileNotFoundError:
        # 파일이 존재하지 않을 경우, 아무 동작도 하지 않음
        pass  # 프로그램이 멈추지 않고 진행됨

# 존재하지 않는 파일 읽기 시도
read_file("non_existent_file.txt")
```
