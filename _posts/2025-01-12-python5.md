# 파일 생성하기
**파일객체 = open(파일 이름, 파일 열기 모드)**  
파일 이름은 문자열이다. 파일 열기 모드에는 r(읽기 모드), w(쓰기 모드), a(추가 모드)가 있다. w은 쓰기 모드로 파일 이름으로 된 파일이 현재 경로에 새로 생성한다. 작업이 끝났다면 `f.close()`를 통해 파일 객체를 닫아준다.
```python
# 파일 생성 및 쓰기
file_name = "example.txt"  # 파일 이름

# 파일을 쓰기 모드로 열기
f = open(file_name, 'w')  # 'w' 모드로 파일 열기 (새 파일 생성)

# 파일에 내용 작성
f.write("안녕하세요, 이 파일은 예시 파일입니다.\n")
f.write("여기에 추가적인 내용을 작성할 수 있습니다.\n")

# 파일 객체 닫기
f.close()

print(f"{file_name} 파일이 생성되었습니다.")
```
```markdown
example.txt 파일이 생성되었습니다.
```

# 파일 읽기
`readline()`: 파일을 한 줄씩 읽는다. while True 조건문과 보통 같이 사용한다.
```python
# 파일 읽기 (readline 예시)
file_name = "example.txt"  # 읽을 파일 이름

# 파일을 읽기 모드로 열기
f = open(file_name, 'r')  # 'r' 모드로 파일 열기

# 한 줄씩 읽기
while True:
    line = f.readline()  # 한 줄 읽기
    if not line:  # 파일의 끝에 도달하면 종료
        break
    print(line.strip())  # 줄 끝의 줄바꿈 문자 제거 후 출력

# 파일 객체 닫기
f.close()
```

<br>

`readlines()`: 파일의 모든 줄을 읽어서 각각의 줄을 요소로 갖는 리스트를 돌려준다. 한글의 경우, encoding = ‘UTF-8”로 해주어야 한다.
```python
# 파일 읽기 (readlines 예시)
file_name = "example.txt"  # 읽을 파일 이름

# 파일을 읽기 모드로 열기
f = open(file_name, 'r', encoding='UTF-8')  # 'r' 모드로 파일 열기

# 모든 줄 읽기
lines = f.readlines()  # 모든 줄을 리스트로 읽기

# 리스트의 각 줄 출력
for line in lines:
    print(line.strip())  # 줄 끝의 줄바꿈 문자 제거 후 출력

# 파일 객체 닫기
f.close()
```

<br>

`read()`: 파일 내용 전체를 문자열로 돌려준다.
```python
# 파일 읽기 (read 예시)
file_name = "example.txt"  # 읽을 파일 이름

# 파일을 읽기 모드로 열기
f = open(file_name, 'r', encoding='UTF-8')  # 'r' 모드로 파일 열기

# 파일 내용 전체 읽기
content = f.read()  # 전체 내용 읽기
print(content)  # 전체 내용 출력

# 파일 객체 닫기
f.close()
```

# 파일 읽고 쓰기
## 파일에 새로운 내용 추가
같은 파일 이름으로 w(쓰기 모드)를를 통해 열었을 때 이미 존재하는 파일의 내용이 사라진다. a(추가 모드)를 통해 기존 파일에 내용을 추가할 수 있다.
```python
# 파일에 내용 추가 (a 모드 사용)
file_name = "example.txt"  # 추가할 파일 이름

# 파일을 추가 모드로 열기
f = open(file_name, 'a')  # 'a' 모드로 파일 열기

# 새로운 내용 추가
f.write("이것은 추가된 내용입니다.\n")
f.write("또 다른 내용을 추가합니다.\n")

# 파일 객체 닫기
f.close()
```

## with 문
위에서는 open -> close 의 구조를 사용했다. with 문을 사용하면 `f.close()`를 자동으로 처리한다. with 블록을 벗어나는 순간 파일 객체 f가 자동으로 닫힌다. open이 반환하는 객체를 as로 변수 선언한다.
```python
# with 문을 사용하여 파일에 내용 추가
file_name = "example.txt"  # 추가할 파일 이름

with open(file_name, 'a') as f:  # 'a' 모드로 파일 열기
    f.write("with 문을 사용하여 추가된 내용입니다.\n")
    f.write("이것도 추가됩니다.\n")
```
